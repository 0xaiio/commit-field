## 复现方式

依赖：Python、`edge-tts`、`Pillow`、`websocket-client`、`numpy`、ffmpeg/ffprobe，以及本机 Microsoft Edge（无头模式）；已在 Python 3.13.14 / edge-tts 7.3.1 / Pillow 12.3.0 / websocket-client 1.9.2 / numpy 2.5.3 / ffmpeg 9.0.2 上实测通过。无需 Node.js 或包管理构建步骤。

```bash
cd video/07_构建
python capture_frames.py     # 从仓库根目录的两个 HTML 采集画面素材
python build_video.py tts    # 语义分句配音 + 时间轴 + 字幕 + 脚本文档 + 校正表
python build_video.py video  # 片段预渲染 + 转场合成 + 音画混流
```

`shots.py` 是唯一时间轴数据源：27 个镜头的素材、旁白编号、转场类型与时长、配音前后留白都在这里定义；旁白正文从 `01_文稿/推广文稿.md` 的 `Nxx｜…` 行读取。`tts_engine.py` 负责分句、静音裁剪、停顿与发音映射；`timeline.json` 是构建时生成的实测时间轴。字幕、配音拼接与 xfade 转场偏移全部由它派生，因此三者不会出现时间漂移。

配音使用 `zh-CN-YunyangNeural`（男声，正常语速 `rate=+0%`）；该语音由 Edge 在线语音服务合成，重新生成需要网络。画面采集完全离线（默认数据内嵌在 HTML 中），仅「自定义账号」镜头需要访问公开接口。S04B 的核验画面来自用户提供的客户端截图，见 `08_活动核验/`。
